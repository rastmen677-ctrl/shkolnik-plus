# Школьник+ — баланс и ручное подтверждение пополнений

Стек: Node.js 22.5+ (в т.ч. 24), Express, встроенная SQLite (node:sqlite, без нативных модулей).

## Запуск
1. `npm install`
2. `cp .env.example .env` и задайте **свои** значения: `ADMIN_PASSWORD`, `PAYMENT_DETAILS`, `JWT_SECRET` (длинная случайная строка). Без `ADMIN_PASSWORD` сервер не запустится.
3. `npm start` → сайт http://localhost:3000, админка http://localhost:3000/admin

Реквизиты можно менять в админке (вкладка «Реквизиты»), они хранятся в БД и приоритетнее `.env`.

## Важно
- Баланс и все суммы в БД хранятся в **копейках**. AI Помощник — платный (39.99 грн, разовая покупка с баланса), бесплатных услуг нет. Если запускали прошлую версию — удалите `data.db`.
- Админка доступна только на `/admin` после входа.
- Суммы — целые гривны. Баланс меняется только функцией `move()` в `server.js` внутри SQL-транзакции.
- Скриншоты лежат в `uploads/` вне `public` и отдаются только владельцу заявки и админу.
- В продакшене используйте HTTPS и `NODE_ENV=production` (cookie получают флаг `secure`). Делайте резервные копии `data.db` и `uploads/`.
- Список заказов в кабинете пока хранится в памяти страницы; через сервер проходит только оплата заказа с баланса.
